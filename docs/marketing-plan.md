# Appidge 线上营销方案（Minimalist Entrepreneur 版 · v2 全职运营排程）

> 框架：先花时间不花钱；营销=规模化的销售；内容三层级（教育→激励→娱乐）；邮件是自有阵地；广告放最后。
> 产品事实约束（红线，所有内容必须遵守）：Appidge **不是 VPN、不含节点**，只把进程流量转给**用户自己的代理**。任何内容不得暗示「翻墙」「科学上网服务」，不与机场/节点商互推。这既是合规红线，也是差异化卖点本身。

---

## 0. 诚实的现状判断

Sahil 的前置条件是「已有 ~100 个付费客户再做营销」。Appidge 处于预上线/刚上线阶段，所以本方案分两个阶段：

- **阶段一（0→100 客户）：一对一销售，不叫营销。** 去痛点现场回答问题、手动交付价值，每一单都是在学习话术。
- **阶段二（100 客户后）：把阶段一学到的东西内容化、规模化。**

阶段一积累的每一次「原来 Docker 不认系统代理」的解释，就是阶段二的内容库。

## 1. 目标人群画像

**核心人群：** 中文 macOS 开发者，日常跑 Clash / Surge / 自建代理，被这些场景坑过：

- Claude Code / Cursor / AI 客户端连不上或超时
- `docker pull` 卡死、pip / npm / go mod 拉包失败
- 终端里 `export https_proxy` 设了一堆还是不生效
- 后台守护进程、语言运行时根本不理系统代理

**关键洞察：这个痛点是搜索驱动的。** 用户不是刷到广告才想买，而是在报错的那一刻去搜「docker 不走代理」「claude code 代理设置」。所以**长尾 SEO 内容是本产品最高杠杆的渠道**，优先级高于社交媒体。

**次要人群（英文）：** r/macapps、Hacker News 上的 Proxifier 替代品寻找者（Proxifier $39.95 vs Appidge $3.99，价格差本身就是故事）。

## 2. 社区矩阵（按投入分层）

### Tier 1 · 每日在场（答题为主，建立身份）

| 社区 | 为什么 | 打法与纪律 |
|---|---|---|
| **V2EX** | 中文开发者代理话题第一现场；帖子 SEO 权重高，答一次被搜三年 | 节点：宽带症候群 / macOS / 程序员 / 分享创造。先答 20 题再发 1 篇「分享创造」帖；签名带链接，回帖不带 |
| **Linux.do** | 当前最活跃的中文技术论坛之一，AI 工具 + 代理配置讨论密度极高，与 Appidge 人群几乎完全重叠 | 有等级制度，先养号：答「Claude Code 连不上」「Docker 代理」类求助帖攒信任级别，再发工具分享帖 |
| **NodeSeek** | 自建代理/服务器人群聚集地，人人手里都有「自己的代理」——正是 Appidge 的前提条件 | 只答技术题（透明代理、分流、回环），谨守非 VPN 红线，这里的用户最能分清工具和节点的区别 |

### Tier 2 · 每周巡逻（发布 + 互动）

| 社区 | 为什么 | 打法 |
|---|---|---|
| **X 中文开发者圈** | build in public 主阵地；Clash/Surge/mihomo 作者和重度用户都在 | 每周 2–3 条进展/复盘；和同类工具作者正常互动，不互吹 |
| **即刻**（效率工具 / MacOS / 独立开发者圈子） | 工具型产品冷启动友好，用户乐于尝鲜 | 每周 1 条产品向短内容，截图优先 |
| **小众软件论坛（meta.appinn.net）** | mac 工具类目精准，主站收录一次≈长期导流 | 论坛发一篇详实介绍帖，争取主站编辑收录 |
| **少数派（sspai）** | Matrix 投稿被收录可获首页曝光，读者付费意愿高 | 把 Level 1 长文改写成 Matrix 投稿，一季度 1–2 篇即可 |
| **Telegram**（Clash / mihomo / Surge 用户群） | 痛点讨论的实时现场 | 只答题、只在被问到时给链接；群规普遍禁广，违规一次身份就没了 |

### Tier 3 · 事件型（发布节点一次性打）

- **Hacker News**（Show HN）、**Product Hunt**、**r/macapps**、**r/macOS**：上线/大版本各一发，目标是被「Proxifier alternative」类搜索长期收录（寄生 SEO），不追求当日爆量
- **目录站登记（一次性，寄生 SEO 性价比最高）**：AlternativeTo、SaaSHub 等「Proxifier alternatives」列表页长期霸占搜索首页，登记一条 Appidge 词条=在别人排好名的页面永久占位，成本约半小时
- **Indie Hackers**：不是卖货渠道（受众是英文独立开发者，不是代理用户），但适合发 Level 2 build in public 故事（「$3.99 工具怎么活」），收益是关注者和外链
- **阮一峰《科技爱好者周刊》投稿**：中文开发者圈最大单点曝光，工具类收录率不低，值得每个大版本投一次
- **《独立开发变现周刊》(ezindie) 等 indie 周刊**：build in public 素材直接投稿

### 明确不做

- **吾爱破解**：盗版关联风险
- **知乎 / 微信公众号 / B 站**：代理类话题审查风险高，删帖甚至封号连累品牌词；等品牌词有自然搜索量后再评估
- **任何机场群 / 节点商渠道互推**：踩红线

## 3. 寻找新社区的方法论（可持续复用）

四条线索找，四个问题筛，一条红线过滤：

**找——顺着线索挖：**
1. **顺着搜索找**：把《排查手册》里的报错关键词（「docker 不走代理」「claude code proxy」…）逐个丢进 Google/Bing，看排在首页的是哪些论坛帖——那就是既有人群又有 SEO 权重的社区。每月做一次，记录进表格。
2. **顺着竞品找**：搜 Proxifier、Surge、Clash Verge、mihomo 的讨论帖/评测出现在哪些站点、哪些 Telegram 群、哪些 YouTube 频道。竞品用户=零教育成本用户。
3. **顺着人找**：X 上转发过同类工具的活跃用户，看他们还活跃在哪（bio 里的即刻/博客/TG 群链接）；Clash/Surge 生态的 GitHub 仓库 issue 区常客，顺着主页找聚集地。
4. **顺着内容找**：自己文章的 referrer 数据——哪个站点持续带来进站，就把它升级为常驻阵地。

**筛——每个候选社区回答四个问题（每题 0–2 分，≥6 分才进矩阵）：**
1. **人群密度**：随便翻 20 个热帖，有几个和 mac/代理/开发相关？
2. **活跃度**：日新帖量、回帖速度如何？（周更论坛不值得每日投入）
3. **推广容忍度**：读版规 + 看既有工具分享帖的存活状态和评论区风向
4. **内容沉淀**：帖子能否被搜索引擎收录？（能沉淀的社区答一题=写一篇小 SEO 文；阅后即焚的群聊只值实时答题）

**过滤——红线检查：** 该平台对代理类话题的审查风险如何？有没有历史删帖/封号案例？有风险的平台只读不发。

**产出物：** 维护一张《社区台账》（社区 / 分层 / 账号状态 / 版规要点 / 最近动作 / 带来的进站数），每月复盘一次，进站为零的社区降级，referrer 里冒出来的新社区补进候选。

## 4. 全职运营每日排程（≈8h）

**每日固定框架：**

| 时段 | 时长 | 工作 |
|---|---|---|
| 09:00–09:30 | 0.5h | 数据晨检：昨日进站/下载/付费三数、搜索收录、referrer 异动；支持邮箱清零（当天回是口碑引擎） |
| 09:30–12:00 | 2.5h | **内容生产**（全天最高杠杆，放精力最好的时段）：按周主题推进 SEO 长文 / 投稿改写 / 邮件 PDF 钩子 |
| 13:30–15:00 | 1.5h | **Tier 1 社区巡逻第一轮**：V2EX、Linux.do、NodeSeek 各 20–30 分钟，目标每天认真回答 3–5 个痛点求助帖 |
| 15:00–15:30 | 0.5h | X / 即刻发布 + 互动：发当日一条（进展/复盘/娱乐短内容），回复评论 |
| 15:30–16:30 | 1h | **每周轮换槽**（见下表） |
| 16:30–17:00 | 0.5h | 素材库维护：把今天答过的题、用户问过的问题记进选题库；社区台账更新 |
| 17:00–17:30 | 0.5h | Tier 1 第二轮快扫（晚间是论坛活跃高峰前哨）+ 支持邮箱再清一次 |
| 17:30–18:00 | 0.5h | 英文侧：r/macapps、HN 相关帖、X 英文圈监测（搜 Proxifier alternative 类新帖并回答） |

**每周轮换槽（15:30–16:30）安排：**

| 周几 | 轮换内容 |
|---|---|
| 周一 | 本周 SEO 文选题定稿 + 关键词调研（顺着搜索找社区，同步做） |
| 周二 | 即刻 / 小众软件论坛 / TG 群巡逻发布 |
| 周三 | 少数派或周刊投稿推进（写作/修改/投递） |
| 周四 | 新社区勘探：按方法论筛 1–2 个候选，读版规、注册养号 |
| 周五 | 周复盘：三数漏斗、各社区进站归因、下周内容排期；每月最后一个周五写月度 newsletter |

**每周产出底线（低于此值说明排程失效）：**
- 1 篇 SEO 长文上线
- 15+ 个社区认真回答（Tier 1 合计）
- 3 条 X/即刻内容
- 1 次投稿或勘探动作
- 支持邮件 100% 当天回复

## 5. 三层内容选题库

### Level 1 · 教育（现在就开始，SEO 主力）

1. 《为什么 Claude Code / Cursor 不走你的系统代理——以及三种解法对比》
2. 《macOS 下 Docker 不走代理的完整排查手册》（`docker pull` 超时全场景）
3. 《终端代理环境变量为什么时灵时不灵：http_proxy 的真实生效范围》
4. 《系统代理、TUN 模式、进程级转发：三种方案的覆盖面和代价》（对应官网 compare 区块）
5. 《代理回环是什么？为什么全局接管流量的工具必须自动排除自己》

> 写法：先把问题彻底讲透、给出不用 Appidge 也能用的解法，最后一段才是「或者用 Appidge 一键解决」。给予优先于索取。

### Level 2 · 激励（build in public，发 X）

1. 一个人在 macOS 上写 Network Extension 是什么体验（系统扩展签名/公证的坑）
2. 「升级黑洞」调查记：一次系统扩展升级导致断网的完整复盘
3. 为什么定价 $3.99 而不是 $39：低价工具的生存逻辑
4. 从 Polar 迁移到 Creem：独立开发者选支付商的真实踩坑
5. 我给自己的产品修的第 N 个 bug：代理软件把自己的更新请求拦了

### Level 3 · 娱乐（有余力再做，X 短内容）

1. 「设了 export https_proxy=… 之后：npm 好了，Docker 没好，我也没好」
2. 系统代理的本质：一个全靠应用自觉的君子协定（配活动进程页截图：谁在装睡）
3. 「非 VPN」声明的一百种问法 vs 我的一种答法
4. 代理软件食物链图鉴：谁在转发谁
5. 用户支持邮件精选：「你们这个不能翻墙啊」——「对，说明书第一行」

## 6. 邮件列表策略

- **钩子（lead magnet）：**《macOS 代理排查手册》PDF——把 Level 1 前三篇整合成 checklist，放在官网博客文末和下载页换邮箱。这正好命中「搜索报错进站」的用户当下需求。
- **收集点：** 博客文末 + 下载完成页（「装好了？这份排查手册留着」）。不弹窗、不强制。
- **节奏：** 每月 1 封：1 个新学到的技术点 + 1 条产品更新 + 1 个用户场景。教育为主，卖为辅。
- **技术：** 已有 `docs/email-setup.md` 的邮件基础设施；列表工具选免费层即可（如 Buttondown/Listmonk），不上重型 marketing automation。

## 7. Build in Public 计划

固定在 X 上分享，素材直接来自开发日常（本仓库 commit 记录就是素材库）：

- **每周一条进展**：本周修了什么、为什么难（如配置对账闭环、XPC 竞态自愈）
- **每月一条数字**：下载量、转化率、退款数——真实数字，包括难看的
- **每次发版一条**：变更点 + 一张活动进程页截图
- **原则**：分享想法和过程，不发「记得买」；写挣扎，不只写胜利

## 8. 付费广告：基本不做

- $3.99 客单价撑不起任何主流 CPC——一次点击可能就超过毛利。**「别花得比单客收入多」在这个价位≈不投广告。**
- 钱花在客户身上而不是获客上：14 天无理由退款体验做好、支持邮件当天回，这是低价工具的口碑引擎。
- 唯一可考虑的付费项（100 客户之后）：中文开发者 newsletter/podcast 的一次性赞助（如科技爱好者周刊类），单次预算 ≤ 已验证的月自然销售额。

## 9. 90 天路线图与度量

| 阶段 | 动作 | 成功标准 |
|---|---|---|
| 第 1–4 周 | 上线；发 3 篇 Level 1 SEO 文；Tier 1 三社区养号答题；Show HN + r/macapps 各一发 | 首批付费用户；搜索开始收录；Linux.do 信任级别达标 |
| 第 5–8 周 | 每周 1 篇博客；邮件钩子 PDF 上线；X build in public 稳定；小众软件/少数派投稿 | 邮件列表 >50；自然搜索进站占比可见；至少 1 篇投稿被收录 |
| 第 9–12 周 | 复盘哪类内容/社区带来转化，砍掉不奏效的，加倍奏效的；周刊投稿 | 100 个付费客户；确定 1 个明确有效渠道 |

**只看三个数：** 自然搜索进站数 → 下载数 → 付费数。每周五复盘漏斗，转化率异常先查产品（试用体验），再查内容。

## 10. 一句话总结

Appidge 的营销不需要「增长黑客」：用户在报错的那一刻会主动来搜。把每个报错场景写成全网最透彻的那篇文章，在痛点现场做一个先给予的社区成员，用邮件留住进站的人，$3.99 的价格自己会完成成交。
