# appidge UI 重构 · 设计原型与计划

`appidge-ui.html` 是本次 UI 重构的**可交互设计原型**（Figma 风格画布，含中英双语与明暗主题）。用浏览器打开即可点开各页、切换语言/主题、平移画布。

## 形态定位

macOS **菜单栏优先**的小工具：常驻菜单栏，点图标弹状态面板；只在看细节时才开主窗口。不是 iOS app、不做 iOS 那套底部 tab。

## 目标 UI 结构

- **⓪ 首次引导**（对应 `App/OnboardingView.swift`）
  一屏：说清能管哪一层（能接管直连出网 / 管不到回环）+ 本机环境探测 + 「开始使用」激活扩展。
  按 Apple HIG 重排：一句承诺 → 能管/管不到两张平白卡 → 技术细节收进「详情」降一层，不再是术语墙。

- **菜单栏下拉**（对应 `MenuBarView`）
  状态行 · 接管层 · 总流量/活动连接 · 流量占用 Top 5 · **打开入口（活动/应用/规则/代理，⌘1–4）** · 紧急恢复直连（重置接管）· 设置…/退出。
  无常驻总开关（开/关＝扩展接管 + 紧急重置）。

- **主窗口 · 顶部分段 tab（取代侧栏）**：活动 · 应用 · 规则 · 代理
  - **活动**：连接表（上）+ **事件日志**（下，可折叠，Proxifier 式，含"命中哪条规则/回环自愈/回退直连"的原因）。去掉带宽图，改文字状态栏 + 每进程速率列。
  - **应用**：逐 App 一个走法开关（走代理/直连/拦截），可主动浏览预设；带「来源」标注。
  - **规则**：有序规则表，首个命中生效；新增 **「来源」列**（自动·默认 `* *` / 自动·回环 xray→直连 / 你），把自动规则如实标出。
  - **代理**：上游服务器 + 路由模式（对应 `ProxyServersPaneView`）。
  - 「档案」折进设置或后续再定。

- **设置页**（对应 `SettingsView.swift`）
  通用（**语言**）· 代理 · 网络接管·恢复出口 · UDP/QUIC · 诊断与抓包 · 内置规则。
  - **删除**「代理环境 · 我们能管哪一层」section（该交底已在首次引导里保留，设置页不重复）。
  - 外观**单一配色**、跟随系统，不做手动切换。
  - 语言切换为新增（`@AppStorage`）。

## 文案基调

原生 macOS 系统文案：短、陈述句、不卖点、不安慰、少破折号。术语翻人话（接管→分流／上游→你的代理／观测→只记录／fail-open→出问题自动恢复直连）。

## 落地顺序（PR 拆分）

1. 设置精简：删「能管哪一层」section。
2. 主窗口 IA：侧栏 → 顶部分段 tab（活动/应用/规则/代理）。
3. 「应用」页：逐 App 走法开关。
4. 活动页：连接表 + 可折叠事件日志；移除带宽图、加速率列。
5. 规则页「来源」列。
6. 菜单栏：加打开入口（⌘1–4）。
7. 设置：语言切换（`@AppStorage`）。
8. 首次引导重排。

每步遵循仓库 `CLAUDE.md` 的 TDD 与"绝不提交破坏现有测试"的纪律，逐 PR 合入。
