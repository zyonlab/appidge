## 标题

被裁在家用 AI 写了个 Proxifier 平替，治 Docker / Claude Code 不走代理的病，求内测

## 正文

年初被裁了，在家试了试 vibe coding，把折磨我很久的事解决了：Clash 开着，Claude Code 照样 timeout，docker pull 卡死——这帮东西根本不理系统代理。Proxifier 能治，但 39.95 刀，我就需要按进程转发这一个功能。

功能不复杂，但 macOS 拦进程流量必须上 Network Extension，开发者账号一年 99 刀。钱都交了，索性做成产品，看能不能把 99 刀挣回来。

东西叫 Appidge：按进程把流量拦下来，转给你自己的 Clash / Surge。点一下进程改规则，当场生效，代理软件自己的流量自动排除不回环。

丑话说前面：不是机场不是 VPN，不带节点，你手里得先有能用的代理。

打算卖 3.99 刀 / 3 台 Mac，免费试用。还在内测，想试的私信我。有问题直接骂，我修得很快——反正在家也没别的事。
